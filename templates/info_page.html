THE PROJECT

About Pixel Forensics Workbench

Pixel Forensics Workbench is an image-analysis workbench for digital investigation, forensic triage, and transparent experimentation. It provides selectable analysis modules that produce measurements and visualizations for an analyst to review.

What it can help with

  • Image properties, channels, histograms, and pixel-level relationships.
  • Candidate anomalies, compression clues, residual views, and Error Level Analysis-style visualizations.
  • Bit-plane and data-hiding screening signals, metadata inspection, and comparison utilities.
  • Candidate periodicity and autostereogram/depth-map exploration.

Interpret results carefully

Outputs are screening signals, not proof of tampering, authenticity, or hidden content. Compression, resizing, sharpening, natural texture, and other benign operations can create false positives. Preserve the original evidence and corroborate findings independently.

DATA HANDLING

Privacy Policy

Last updated: 18 October 2026

Images and analysis results

Images are uploaded to this service for server-side analysis. The application targets deletion of each upload, generated visualization, and temporary report file at the 10-minute threshold from upload. A background cleanup process checks for expired files approximately every 15 seconds, and expired session files are also cleaned on startup. If an analysis is still actively running at the threshold, cleanup waits for that job to finish, so retention can exceed 10 minutes in that case.

Cleanup is best-effort, not a guarantee of secure erasure from storage media, backups, snapshots, operating-system caches, or infrastructure-level logs. The operator must configure the server, backups, and storage accordingly. Do not upload highly sensitive images unless you are comfortable with this handling.

Technical data

The application may process basic request information such as IP address for short-window abuse controls and operational errors. Server and reverse-proxy logs may be configured separately by the hosting operator. This application is not intended to store user accounts or long-term image archives.

Third-party services

The host, domain provider, CDN, reverse proxy, or other infrastructure services may process connection metadata according to their own terms and settings. The operator should document any services actually enabled before public launch.

Your choices

Do not upload images you are not authorized to analyze. Use the Clear control to request immediate deletion of the active session. You can stop using the service at any time.
